# 视觉引导智能小车系统 / Vision-Guided Smart Car System

基于树莓派 + Raspblock 平台，融合二维码识别、颜色识别、云台追踪与自主运动控制的机器人视觉综合项目。

---

## 项目简介

本项目整合了《系统设计与开发II》系列实验，通过摄像头采集环境信息，利用 OpenCV 实现二维码识别与颜色识别，结合 PID 控制算法驱动云台追踪目标，并通过多线程架构实现低延迟的感知—决策—执行闭环。

核心能力：
- 识别二维码指令（forward / backward / left / right / stop）控制小车运动
- HSV 颜色空间识别红/绿/黄等目标，双轴云台实时追踪
- 三阶段自主探测任务（直行 → 识别 STOP 二维码 → 原路返航）
- 语音播报识别到的颜色、GUI 按钮控制、紧急停止机制

## 关键技术细节

### 摄像头低延迟优化
- 使用 V4L2 驱动（`cv2.CAP_V4L2`）
- 分辨率 320×240，帧率 30-60 FPS
- 缓冲区大小设为 1（`CAP_PROP_BUFFERSIZE=1`）
- 固定曝光、关闭自动对焦，避免自动调整带来的延迟
- 缩小图像至 160×120 进行二维码解码
- JPEG 编码质量降至 70（二维码）/ 30（颜色追踪）

### 颜色识别
- 使用 HSV 色彩空间，对光照变化不敏感
- 红色采用双阈值法（0-10 和 170-180）
- 中心区域掩码过滤，减少边缘干扰
- 面积阈值过滤（最小 100 / 最大 10000 像素）

### PID 云台控制
- 比例-积分-微分控制，参数 Kp=1.0, Ki=0.05, Kd=0.2
- 计算目标质心与图像中心的偏差，输出舵机 PWM 调整量
- 死区过滤（dead_zone=10），减少微小抖动
- PWM 范围限制 800-2200 μs

### 多线程安全
- 摄像头采集线程 + 运动控制线程独立运行
- threading.Lock 保护共享资源（摄像头帧、指令状态）
- 守护线程确保程序退出时自动释放硬件资源
- 异常捕获确保摄像头和电机安全停止

## 实验结果

系统实现了以下功能：
1. 摄像头实时识别二维码指令并控制小车前进/后退/左转/右转/停止
2. 云台能够稳定追踪指定颜色目标（红/绿/黄/橙），延迟 30-50ms
3. 综合模式下，小车可完成自主探测任务：直行 → 转弯 → 识别 STOP → 返航
4. 语音模块实时播报识别到的颜色名称

- 掌握了通过 Python 控制硬件（电机、舵机）的方法
- 理解了安全紧急停止机制和资源释放的重要性
